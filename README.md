# Behar Kabab House - Desktop POS

A NativePHP (Laravel + Electron) desktop Point of Sale application for restaurant management. Built with Laravel 13, Vue/JS, Vite, and NativePHP Desktop.

## Features

- **POS Terminal** - Dine-in, takeaway, delivery orders with cart, modifiers, variants, discounts
- **Kitchen Display** - Order queue with status tracking
- **Orders Management** - Order history, status updates, refunds, receipts
- **Tables** - Table management and status tracking
- **Menu Management** - Categories, products, modifiers, recipes
- **Inventory** - Stock tracking, purchases, suppliers, stock movements
- **Shifts** - Cashier shifts with opening/closing, cash in/out, variance
- **Expenses** - Expense tracking by category
